지원

집에 뭐가 있는지 기억하는 앱

영수증을 한 번 찍으면 품목이 읽히고, 냉장고·팬트리 같은 장소로 끌어다 놓으면 정리됩니다. 유통기한을 넣어두면 상하기 전에 알려드리고, 초성만 쳐도 찾습니다.

로그인이 없습니다. 물건 목록은 이용자의 기기에 있습니다.

자주 묻는 질문

영수증이 잘 안 읽혀요

영수증을 평평하게 펴고 밝은 곳에서, 영수증 전체가 화면에 들어오게 찍어 주세요. 구겨지거나 그림자가 진 부분은 글자가 뭉개집니다. 감열지 영수증은 시간이 지나면 인쇄가 흐려져 읽기 어려워집니다 — 받은 날 찍는 편이 가장 잘 읽힙니다.

읽은 결과가 틀렸어요

확인 화면에서 저장하기 전에 고칠 수 있습니다. 이름, 수량, 장소, 유통기한 모두 그 자리에서 바꿉니다. 필요 없는 줄은 체크를 꺼서 빼면 됩니다. 저장한 뒤에도 물건을 눌러 언제든 고칠 수 있습니다.

스캔이 안 돼요

세 가지를 확인해 주세요.

  • 인터넷 연결 — 영수증을 읽을 때만 연결이 필요합니다. 나머지 기능은 연결 없이 씁니다.
  • 이번 달 무료 횟수 — 30장을 다 쓰셨다면 다음 달까지 기다리거나 본인 API 키를 쓰실 수 있습니다(아래).
  • 서버 일시 장애 — “스캔 서버가 잠시 응답하지 않아요”가 뜨면 잠시 후 다시 시도해 주세요. 찍어 둔 영수증은 처리 대기로 남아 있어 나중에 이어서 읽을 수 있습니다.

매달 몇 장까지 무료인가요

영수증 스캔은 매달 30장까지 무료입니다. 매달 1일 오전 9시(한국 시간)에 다시 채워집니다. 직접 물건을 추가하고, 정리하고, 알림을 받는 기능에는 제한이 없습니다.

알림이 안 와요

알림은 유통기한을 넣은 물건에만 갑니다. 며칠 전에 받을지, 몇 시에 받을지는 설정 > 유통기한 알림에서 정합니다.

그래도 오지 않으면 기기의 알림 허용을 확인해 주세요 — iOS는 설정 앱 > 알림 > Itne, Android는 설정 > 앱 > Itne > 알림입니다. 앱의 설정 화면에서도 바로 열 수 있습니다.

다른 기기와 목록이 안 맞아요

iPhone·iPad는 같은 Apple 계정을 쓰는 본인 기기끼리 iCloud로 목록을 맞춥니다. 두 기기가 같은 계정으로 로그인돼 있고 iCloud가 켜져 있는지, 인터넷에 연결돼 있는지 확인해 주세요. 처음 맞출 때는 시간이 조금 걸립니다.

Android는 동기화가 없습니다. 기록이 그 기기에만 있고, Android와 iPhone 사이에서는 맞춰지지 않습니다.

물건을 다른 장소로 옮기려면

물건을 길게 눌러 아래의 장소 타일로 끌어다 놓으세요. 여러 개를 한 번에 옮기려면 미분류 목록의 선택을 누르고 고른 뒤 옮깁니다. 물건을 눌러 상세 화면에서 장소를 고르셔도 됩니다.

이름이 기억나지 않아요

초성만 쳐도 찾습니다. “ㄱㅈㅈ” 만 치면 건전지가 나옵니다. 메모에 적어 둔 말로도 찾을 수 있습니다.

iPad는 뭐가 다른가요

iPad에서는 물건 탭이 분류 스테이션으로 열립니다. 왼쪽에 아직 자리를 못 정한 물건이, 오른쪽에 장소 상자들이 놓여서 끌어다 놓기가 훨씬 편합니다.

제 API 키를 쓰고 싶어요

설정 > 영수증 파싱 > API 키·모델에서 Itne 서버 대신 본인이 발급한 키를 쓰도록 바꿀 수 있습니다. 이 경우 월 30장 한도가 적용되지 않고, 비용은 해당 계정으로 청구됩니다. 키는 기기에 암호화해 보관하며 Itne 서버로 보내지 않습니다.

기기를 바꾸면 기록이 옮겨지나요

iPhone·iPad — 같은 Apple 계정을 쓰시면 iCloud 동기화와 백업으로 따라옵니다.

Android — 아니요. 백업 기능이 없어 앱을 지우거나 기기를 바꾸면 되돌릴 수 없습니다.

필요한 환경

  • iPhone·iPad — iOS 26 이상
  • Android — Android 8.0 이상
  • 한국어 전용입니다. 영수증도 한국 영수증 기준이라, 금액을 원 단위로 읽습니다 — 다른 통화의 영수증은 제대로 들어가지 않습니다.
